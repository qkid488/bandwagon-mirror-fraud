## 怎么识别假搬瓦工网站

仿冒站的页面可以抄得很像，但域名骗不了人。核对下面几条，基本能过滤掉绝大多数假货：

1. **只认两类域名**：`bandwagonhost.com` 主站，以及 `bwhXX.net` 形式的官方镜像。其他任何“banwagong”“bwg”“bandwagonhost”混着数字和杂乱后缀的变体域名，都不要在里面输入账号密码。
2. **检查 HTTPS 证书**：官方所有入口都有有效的 SSL 证书，浏览器地址栏有锁形图标。没有锁，或者证书对不上域名，直接关掉。
3. **不要从搜索引擎广告和陌生群文件进**：仿冒站主要靠搜索广告和群友转发传播。从你确认过的域名手动输入，是最稳的方式。
4. **登录页面前再确认一次域名**：钓鱼站常在登录环节做手脚。输密码之前看一眼地址栏，两秒钟的事。
